# JEE-mark-tracker
PROMPT:
Create a beginner-friendly web application called JEE Performance Tracker to help students track their performance in JEE mock examinations.
1. Main Objective
The website should allow students to enter their marks every time they complete a JEE mock test and monitor their academic progress through graphs and performance analysis.
2. Dashboard
Create a clean dashboard displaying:
Total number of mock tests attempted.
Highest marks scored.
Lowest marks scored.
Average marks.
Most recent test score.
Overall improvement or decline in performance.
3. Add Mock Test
Provide an input section where students can enter:
Mock test name or test number.
Exam date.
Physics marks.
Chemistry marks.
Mathematics marks.
Calculate the total marks automatically out of 300.
Include an Add Test button to save each examination's results.
4. Performance Graph
Display a line graph showing:
X-axis: Mock test number or exam date.
Y-axis: Total marks scored.
A separate point for every mock test.
Connect the points to show improvement or decline.
5. Performance Analysis
Use basic calculations to display:
Highest-scoring test.
Lowest-scoring test.
Average score.
Improvement between consecutive tests.
Subject-wise highest marks.
Subject that needs more improvement.
6. Mock Test History
Display all previously entered tests in a table with:
Test name.
Date.
Physics marks.
Chemistry marks.
Mathematics marks.
Total marks.
Include an option to delete an individual test.
7. Design Requirements
Modern, clean student dashboard.
Light background with blue and purple accents.
Separate cards for performance statistics.
Responsive layout for mobile and desktop.
Clear input fields and buttons.
Easy-to-understand graphs.
8. Technology Restrictions
Use only:
HTML for webpage structure.
CSS for styling and responsiveness.
Basic JavaScript for calculations, arrays, loops, conditions, and DOM manipulation.
Do not use React, Angular, backend databases, APIs, advanced JavaScript frameworks, or complex libraries.
Use beginner-friendly code with simple variable names, functions, arrays, and loops.
The final application should be functional, easy to understand, and suitable for a beginner to explain in a technical interview.
